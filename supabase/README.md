# Supabase Kurulum (v10)
1. supabase.com'da yeni proje ac.
2. Sol menude SQL Editor'u ac.
3. `migrations/001_init.sql` icerigini yapistir.
4. Run'a bas, hata yoksa tamamdir.
5. Project Settings > API'den URL ve anon key al.
6. `.env` dosyasina `VITE_SUPABASE_URL` ve `VITE_SUPABASE_KEY` yaz.
7. Storage'da `songs` ve `covers` bucket'larini kontrol et.
